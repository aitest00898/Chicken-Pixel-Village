# Acceptance Criteria

- All six primary routes are reachable and back navigation is coherent.
- Public data shows source date, unit, source, validation/cache status and frequency.
- Private entities are separate and auditable; ratios and money are integers.
- Confirmed and paid distributions cannot be silently edited or deleted.
- Native storage has migrations and an outbox; Web storage is explicitly a cache.
- Houses use `designCapacity` for single/double/triple-row art at exact boundaries.
- Equipment never affects product or financial state.
- No secrets, real personal fixtures, production deployment, external remote or paid resource exists.
- Lint, strict typecheck, unit tests and Web build pass. Platform checks are reported truthfully.
