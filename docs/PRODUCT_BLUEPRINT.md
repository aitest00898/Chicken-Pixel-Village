# Product Blueprint

## Product promise

《雞情像素村》把公開家禽行情與私人雞舍營運放進同一個手機優先產品，但嚴格區分公開資料、私人資料與不同更新頻率。遊戲化只服務於巡查與資訊理解，不改變財務或資料權限。

## First release scope

- 啟動畫面、RPG 主選單、今日雞情、歷史行情、我的村莊、我的雞舍、管理者、設定。
- 公開雞蛋、白肉雞、紅羽與黑羽行情；商業雛雞維持明確的週／月參考價語意。
- 雞舍、批次、代養戶、股東、持股、分潤、5M1E 風險、地圖配置與 audit trail。
- 每日巡村、累積與連續到訪、外觀裝備解鎖及四個純外觀槽位。
- 離線讀取、草稿、outbox、重試、revision 與財務衝突停等。

## Explicit exclusions

戰鬥、抽卡、虛擬貨幣、付費裝備、養成數值、經營模擬、排行榜與玩家社群不在第一版。
