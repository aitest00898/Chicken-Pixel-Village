# UX Flow

1. Launch reads local cache immediately and shows a real stage label, never fake progress.
2. Main menu exposes all six primary destinations and a market summary without an extra tap.
3. Browser, Android and in-app back actions follow the same route history.
4. Public routes: launch, market today, history, public village tour, sources.
5. Private routes: houses, batches, shareholders, distributions, risk and cross-device equipment.
6. Offline private changes remain drafts with a persistent message that online confirmation is required.
7. Every screen supports 320 CSS px, safe-area insets, reduced motion, dark mode, keyboard focus and touch targets of at least 44 px.
